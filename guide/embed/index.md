# 嵌入式设备组网

:::warning
EasyTier-ESP 现在为预览版本，仅实现了部分基础功能，接口在今后可能出现变更，且可能存在未知问题，请慎用于生产环境。
:::

EasyTier-ESP 是 EasyTier 组网协议在 ESP-IDF 上的 C++ 轻量级实现组件，
可用于 ESP32 嵌入式设备的异地组网，让物联网设备轻松接入 EasyTier 虚拟网络。
本组件的设计目标并非 EasyTier 的所有功能，而是实现了与 ESP32 单片机的性能以及物联网设备需求相匹配的功能子集。

**组件信息如下**：
- ESP组件注册表：myqfeng/easytier-esp
- 当前适配：ESP-IDF >=6.1
- 已验证目标：ESP32-S3-N16R8
