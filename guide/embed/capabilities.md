# 支持能力说明

EasyTier-ESP 没有实现 EasyTier 的完整协议，以下是本项目支持的能力说明。

| 能力 | 状态 | 说明 |
| --- | --- | --- |
| TCP 客户端入口 | ✅ 支持 | `[[peer]].uri = "tcp://host:port"`，支持 IPv4 与 DNS 主机名 |
| 多入口 | ✅ 支持 | 条目数量无上限；同时连接数由 Kconfig 限制（默认 6，范围 1..8） |
| 非安全模式握手 | ✅ 支持 | 网络名 + 密钥摘要校验；不是 Noise |
| 自动保活 | ✅ 支持 | 自动探测断线并重连 |
| 控制面 RPC | ✅ 支持 | 用于路由同步等控制面请求/响应 |
| 路由同步 | ✅ 支持 | 自动学习虚拟网络拓扑与下一跳 |
| 数据转发（中继） | ✅ 支持 | 可作为中继转发其他节点的数据 |
| AES-128-GCM | ✅ 支持 | 数据面加密 |
| 关闭加密 | ✅ 支持 | 可通过 `flags.enable_encryption = false` 关闭 |
| 静态虚拟 IPv4 | ✅ 支持 | `ipv4 = "10.144.144.10/24"` |
| DHCP 自分配 | ✅ 支持 | `dhcp = true` 或 CIDR；回落 `10.126.126.0/24` |
| lwIP 虚拟网卡 | ✅ 支持 | 标准虚拟网卡，不抢占默认路由 |
| 多实例 | ✅ 支持 | 每个 `et::Inst` 独占资源 |
| 事件回调 | ✅ 支持 | 状态变化通知；`PeerDown` 当前预留 |
| 入站监听 | ❌ 不支持 | 组件不监听端口，不能被其他节点主动连入 |
| UDP / KCP / QUIC / WebSocket | ❌ 不支持 | 只实现 TCP 客户端传输 |
| Noise 安全模式 | ❌ 不支持 | 仅非安全模式握手 |
| 子网代理 / `proxy_network` | ❌ 不支持 | 配置字段会被忽略 |
| 静态路由 / `routes` | ❌ 不支持 | 配置字段会被忽略 |
| 广播 / 组播 | ❌ 不支持 | 出站广播/组播直接丢弃并计数 |
| IPv6 入口 | ❌ 不支持 | `peer.uri` 只接受 TCP + IPv4/DNS |
| Zstd 压缩 | ❌ 不支持 | 收到 Zstd 压缩的 RPC 会报错并撤销 Ready |
| 图形界面 / Web 面板 | ❌ 不提供 | 只有 C++ 组件与示例 |
| TLS | ❌ 不支持 | TCP 传输本身不加密；数据面由 AES-GCM 保护 |


:::tip
未列出的能力默认视为**未支持**。
:::
