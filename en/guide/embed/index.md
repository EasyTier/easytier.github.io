# Embedded Device Networking

:::warning
EasyTier-ESP is currently in preview. Only basic features are implemented, its APIs may change in the future, and unknown issues may exist. Use it with caution in production environments.
:::

EasyTier-ESP is a lightweight C++ implementation of the EasyTier networking protocol on ESP-IDF.
It can be used for cross-site networking of ESP32 embedded devices, making it easy for IoT devices to join an EasyTier virtual network.
This component is not designed to implement all EasyTier features; instead, it implements a subset that matches the performance of ESP32 microcontrollers and the requirements of IoT devices.

**Component information**:
- ESP Component Registry: myqfeng/easytier-esp
- Currently compatible with: ESP-IDF >=6.1
- Verified target: ESP32-S3-N16R8

**Source repositories**:
- [Github.com/EasyTier/easytier-esp](https://github.com/EasyTier/easytier-esp)
